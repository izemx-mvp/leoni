# LEONI Workforce Navigator

PROJET

======

Créer une application web Backoffice Enterprise de très haute qualité pour LEONI Maroc appelée :

LEONI WORKFORCE JOURNEY

Sous-titre :

Pilotage du recrutement, de la formation et de l’intégration des opérateurs

IMPORTANT :

Il s’agit d’un prototype fonctionnel destiné à être présenté à un grand groupe industriel.

Ne pas créer une simple succession de maquettes.

Créer une véritable application interactive comprenant :

- navigation complète ;

- données mockées réalistes ;

- tableaux fonctionnels ;

- filtres ;

- recherche ;

- formulaires ;

- modales ;

- graphiques ;

- calendrier ;

- Kanban ;

- notifications ;

- changements de statuts ;

- historique ;

- Light Mode ;

- Dark Mode ;

- interactions entre les différents modules.

Toute l’interface doit être en FRANÇAIS.

Aucun Lorem Ipsum.

Toutes les personnes, matricules, scores, statistiques opérationnelles et événements individuels utilisés dans la démo sont fictifs.

==================================================

1. CONTEXTE MÉTIER

==================================================

La plateforme est destinée à gérer le parcours complet des candidats et futurs ouvriers/opérateurs dans un environnement industriel automobile.

Le parcours métier est :

1. Réception automatique de la candidature

2. Lecture automatique du CV et des documents par IA

3. Création automatique du dossier candidat

4. Analyse du profil

5. Scoring IA par rapport au besoin/poste

6. Présélection

7. Confirmation / qualification RH

8. Planification éventuelle d’un entretien

9. Réalisation et évaluation de l’entretien

10. Décision humaine RH

11. Création automatique de la fiche ouvrier

12. Affectation à un site / poste / groupe

13. Affectation à un parcours de formation

14. Génération du planning

15. Communication automatique du planning

16. Suivi quotidien de la formation

17. Suivi des présences / retards / absences

18. Tests et QCM

19. Évaluations pratiques

20. Observations des formateurs

21. Actions correctives et rattrapages

22. Analyse globale du parcours par IA

23. Détection des profils à risque

24. Recommandation IA

25. Décision humaine finale :

    - confirmation

    - prolongation

    - réorientation

    - suspension

    - arrêt du parcours

26. Archivage et traçabilité complète

- dans Synthèse ;

1. ajouter le retard à Présence ;

3. recalculer ponctualité ;

4. vérifier règle d’alerte ;

5. mettre à jour Worker Readiness Score si nécessaire ;

6. ajouter événement à l’historique.

Khadija échoue QCM sécurité avec 55 %.

Le système :

1. stocke résultat QCM ;

2. met compétence sécurité « À renforcer » ;

3. crée rattrapage ;

4. crée alerte ;

5. modifie risque ;

6. remonte dans Synthèse ;

7. alimente analyse IA ;

8. écrit l’événement dans historique.
